# 用户需求与最终设计决定

记录日期：2026-10-16（Asia/Tokyo）。本文是后续工作的需求基准，不表示各项已经实现。

## 产品与技术

1. APP 名称为 **NOCA**。
2. 用手机 NFC 读取日本交通 IC 卡，查看余额和交易记录。
3. 底层使用 Rust，Android 界面使用 Jetpack Compose。
4. UI 以 Material 3 Expressive 为主，框、按钮等控件加入 Soft UI 风格。
5. 最低 Android 10，支持 Android 17。
6. 最终只交付 **ARM64 / arm64-v8a APK**，不混入其他架构；x86_64 仅允许内部调试。
7. 项目提交到用户指定仓库：<https://github.com/Stickmin522/NOCA>。

## 功能

1. 打开 APP 后可贴卡读取，无需先选择卡种。
2. 读取成功显示余额和最近交易。
3. 用户可以选择“记住这张卡”；选择后弹出输入卡名称的对话框。
4. 独立卡包页面列出已记住的卡，可打开查看余额和交易记录。
5. 已保存卡可编辑名称和卡面，卡面可选择日本目前正常发行的交通卡卡面。
6. 再次识别同一张已保存卡时，自动同步余额和交易记录，保留用户设置的名称与卡面。
7. 支持所有系统语言，字体使用系统字体。语言设置可跟随系统，或手动选其他语言。

## 最终 UI 决定

| 项目 | 用户选定方案 |
| --- | --- |
| 品牌名称 | NOCA，不能误写为 NOKA |
| APP 图标 | 使用早期 NOKA 的图标设计：倾斜卡片与 NFC 波纹 |
| 基础布局 | NOKA 的设计 |
| 读卡等待区域 | NOKA 读卡页的“等待贴卡”位置 |
| 上次读取 | 删除单独的“上次读取”框 |
| 读取成功 | 在原“等待贴卡”的位置显示余额，下方展示最近交易 |
| 余额容器 | 使用 SUMI 的票券设计，但颜色匹配当前主题 |
| 卡包与卡片详情 | 沿用 NOKA；余额展示也采用主题色票券设计 |
| 其余界面 | NOKA 风格 |
| 主题 | 活力青柠、雾蓝、暖珊瑚；仅换颜色，不能切换为三套不同布局 |

用户最初要求先提供多套名称、UI、卡包、设置和图标供审查，再按选择开展开发。早期原型包含 NOKA / KASANE / SUMI，属于方案探索历史，不应直接覆盖上述最终决定。
