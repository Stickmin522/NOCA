# 当前工作快照

截至 2026-10-16（日本时间）。开发已按用户要求暂停。下面区分“代码已写”与“已经验证”，避免将初稿当作完成品。

## 已有代码

### Rust 核心

- FeliCa Read Without Encryption 请求构造，IDm、服务和块号编码。
- 响应长度、命令、IDm、状态与数据块校验。
- 属性块余额解析；历史记录日期、余额、流水号和站点编码字段解析。
- 仅在流水号相邻时推算交易差额，不凭缺失记录编造交易金额。
- 有界 C FFI 导出、JNI C 桥接和 Kotlin NativeCore 接口。
- 无第三方 Rust crate 依赖。

### Android 功能初稿

- NFC-F ReaderMode，交通卡系统轮询、属性与历史服务读取，读卡失败与部分记录状态处理。
- SQLite 保存卡片与历史记录；同一卡再次读取时同步，保留名称和卡面；记录去重。
- 读卡并发限制和短时重复识别抑制；命名对话框绑定打开时的快照。
- Compose 读卡页、卡包、卡片详情、设置、命名、编辑卡片及语言选择界面。
- 同位置切换等待状态与票券余额；余额下方最近交易；不保留独立“上次读取”面板。
- 三种主题颜色、明暗/系统模式、系统字体、轻阴影与票券形状。
- 自适应启动图标及 monochrome 图层，采用 NOKA 图案，应用名 NOCA。
- 当前没有 INTERNET 权限；读取和保存按本地处理设计。

### 资源与设计

- 40 个语言 JSON 资源，另有语言索引；英语、简体中文和日语有单独处理，其他资源多为机器翻译，尚未逐语种审校。
- 候选语言清单约 90 项，并非已完成语言清单，也不是 Android 所有地区语言的权威全集。
- 卡面：Suica、PASMO、ICOCA、Kitaca、TOICA、SUGOCA、nimoca、PiTaPa，另有 NOCA 通用样式。
- 保存初始三方案 HTML、预览 HTML、相关 worker 和预览卡面素材。
- 对话中生成的图像概念板未作为本地文件进入本次快照；已有可用 HTML 设计文件与最终文字规范均已收录。本仓库不声称包含对话中所有生成图片。

## 已完成验证

- Rust 单元测试：**8 项通过**，覆盖请求编码、响应匹配/错误、余额字节序、日期有效性、相邻流水差额和空记录。
- Rust `aarch64-linux-android` release 静态库曾成功交叉编译。生成的二进制位于临时构建目录，未作为源码提交。
- 已配置 `minSdk=29`、`targetSdk=37`、`compileSdk=37` 和仅 `arm64-v8a`。

以上 Rust 验证不等于 Android APP 可运行。此次归档没有继续执行构建或测试。

## 未完成与已知待查事项

- Android 整体构建尚未成功；此前被构建进程/网络与依赖解析问题阻断，还未完成 Kotlin/Compose 的完整编译验证。
- 没有可安装 APK，没有签名发布包，没有模拟器或实体手机验收。
- NFC 实卡读取、各卡种兼容性、余额与历史正确性、重复同步都需设备验证。
- PiTaPa 卡面资源不代表已经支持其后付费账单；当前实现围绕交通 IC 预付余额与有限卡内历史。
- 站点编码已保留，但完整站名数据库与商户名称解析未实现；不应宣称能还原卡片未提供的信息。
- “所有系统语言”尚未完成，需补充翻译、校对、RTL 与长文本布局验证。
- 卡面没有覆盖全部日本发行卡种；新增的五张素材仍需逐一核对内容、分辨率与展示效果。
- 深色主题部分 raised 色值、Material 默认次级容器颜色需核对是否完全随主题切换。
- 通用卡面的 JSON null 读取行为需核对。
- 历史合并、编辑时同步、应用重建与数据库升级需测试。
- 无 Gradle Wrapper；现有本机排障脚本不可直接用于其他电脑。
- 无 CI 发布流水线、APK ABI/16 KB 页验证或正式发布说明。
